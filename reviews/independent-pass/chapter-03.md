## 源文问题独立核验

- **Java初始化**：本版PDF59确有 package-level initialization using static initializers；[Java SE8语言规范§8.7](https://docs.oracle.com/javase/specs/jls/se8/html/jls-8.html#jls-8.7)明确静态初始化器在类初始化时执行、可初始化类变量。这是类机制，不能当成包级初始化机制。正文保留，增加译注；使用出版前已有规范，不按新版本改写历史。
- **JAR版本**：PDF60确将加入JAR记作1.2；[Oracle Java SE11安全架构的历史回顾](https://docs.oracle.com/en/java/javase/11/security/java-se-platform-security-architecture.html)在JDK1.1安全模型段已描述签名applet用JAR交付。足以证明JAR在1.1已使用；本次译注只陈述这一证据，不以推测确定更早起源。原有笔记“不曾外部核实”的状态将更新。
- **LCOM**：PDF62公式确用集合基数差与条件，正文却说P加一、Q减一；PDF63式3-2确为(1/a)求和(m-μ(Aj))/m，后续“方法组”解释未提供等价计数规则；保留现有译注，不替作者换公式。
- **抽象度**：PDF65式3-3分母确为具体制品总数，正文又以1/5000代码行解释；PDF66主要将A作为0–1数值。保留原文与现有译注；不擅自把分母改成全部类。
- **距离**：PDF66式3-5的绝对值在文本提取时容易丢失，页面为D=|A+I−1|；译稿正确。PDF67图题称归一化距离，不能因图中的垂线示意而自行在公式中补除√2。
