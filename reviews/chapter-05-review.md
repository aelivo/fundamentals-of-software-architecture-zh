## 原书问题及审校边界

- 瓦萨号故事按原文保留，包括年代、火炮、沉没与打捞叙述。本轮进行翻译校译，没有另行核验历史细节，现有译注不删除。
- 初始需求写作 must integrate with several external mapping services，后文第 1 项分析重述为 must provide the option to integrate with external mapping services。译文分别保留两处措辞，这项原文差异不归为初稿译错，也不擅自统一；但重述中 must provide 的必需性在初稿未充分体现，本轮另行补回。
- native web applications 已在 PDF 第 92 页渲染图中确认，保留“原生 Web 应用”与原有译注，不代替作者改成其他应用类别。
