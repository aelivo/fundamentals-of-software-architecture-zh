## 工作方式

1. 阅读一个完整小节，记录问题。
2. 按[翻译约定](translation-guide.md)翻译，查询并更新[术语表](glossary.md)。
3. 对照原文校订，检查否定、条件、因果、限定词与图表。
4. 在独立笔记中记录理解、项目联系与疑问。
5. 更新进度，按可独立审阅的段落或小节提交 Git。

尚未解决的跨章节问题记录在 [open-questions.md](reviews/open-questions.md)。
